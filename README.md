# Advanced Reboot

Advanced Reboot — отдельное Android-приложение для диагностики и безопасного доступа к доступным режимам перезагрузки устройства.

## Цели первой версии

- автоматически определить производителя, модель и версию Android;
- определить системную оболочку, когда это возможно;
- не показывать недоступный режим как рабочий;
- объяснять причину недоступности: права, ограничения устройства/ПО или неопределённость;
- подготовить архитектуру для будущих провайдеров ADB, Shizuku и root.

### Важно

Обычное Android-приложение не может само выдать себе привилегированные системные права. Поэтому первая версия намеренно не выполняет опасные/привилегированные команды через скрытые обходы.
